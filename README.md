This project uses [`uv`](https://github.com/astral-sh/uv) for fast dependency management and execution.

## Setup & Run

1. Install `uv`:

   ```bash
   pip install uv
   ```

2. Sync dependencies:
   ```bash
   uv sync
   ```
3. Run the app:
   ```bash
   uv run streamlit run app.py
   ```
